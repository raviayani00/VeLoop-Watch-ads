# ⚡ VELOOP Rewards - Watch Ads Dashboard

A modern, responsive fintech-themed web application built with **React.js** and **Vite** where users can watch short advertisements, earn VEs (reward tokens), track their daily streaks, and monitor earnings.

---

## 🛠️ Technologies Used (Tech Stack)

Is project ko banane ke liye in modern tools aur libraries ka use kiya gaya hai:

* **Frontend Library**: **React.js** (v18+) – Component-based UI development ke liye.
* **Build Tool**: **Vite** – Fast development server aur lightning-fast builds ke liye.
* **Styling & UI**: **Bootstrap 5** & **Custom CSS Modules** – Responsive layout aur styling ke liye.
* **Icons**: **Lucide React** – Clean aur modern vector icons ke liye.
* **Animations / Effects**: **Canvas Confetti** – Ad complete hone par celebratory confetti animations ke liye.
* **Version Control**: **Git & GitHub** – Code tracking aur repository hosting ke liye.

---

## 🚀 Key Features

* **Interactive Ad Grid**: Watch advertisements with live countdown timers and instant confetti rewards upon completion.
* **Collapsible Sidebar**: Smooth expandable/collapsible sidebar navigation with custom dashboard tabs (*Dashboard, Watch Ads, Rewards, Wallet, History, Profile, Settings*).
* **Live Earnings Tracker**: Real-time updates for Today's Earnings, Lifetime Earnings, Ads Watched, and Remaining Ads.
* **Daily Streak & Progress**: Visual daily streak tracker and progress bar toward daily goals.
* **Dark Mode UI**: Sleek, professional dark-themed interface built using Bootstrap 5.

## 📥 Getting Started & Installation

To run this project locally on your machine, follow these simple steps:

### 1. Clone the Repository
```bash
git clone [https://github.com/raviayani00/veloop-watch-ads.git]

cd veloop-watch-ads

```

### 2. Install Dependencies

Make sure you have Node.js installed, then run:

```bash
npm install

```

### 3. Run the Development Server

```bash
npm run dev

```

Open your browser and click on the local link provided in the terminal (usually `http://localhost:5173`).
